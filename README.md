# ON TAP

Bạn học AI giúp học sinh ôn lại đúng những gì đã học ở trường, phát hiện chỗ yếu và nhớ lâu hơn.

**Bản MVP:** môn Toán, lớp 4 · chạy dạng Web/PWA (mở bằng trình duyệt điện thoại, cài ra màn hình chính).

## Chạy thử trên máy (dành cho người kỹ thuật)

```bash
npm install
npm run dev
```

Mở địa chỉ hiện ra (mặc định http://localhost:5173).

## Công nghệ

- Giao diện: Vite + React (PWA)
- Dữ liệu & đăng nhập: Supabase *(nối ở bước sau)*
- Bộ não AI: Claude API *(nối ở bước sau)*
- Chạy online: Vercel
